♔ CS 240 Chess Server

The CS 240 Chess Server Web API is described below. Some of the APIs require a request body to be sent (like /userData/login and /userData/register), while others require an Authorization authData (received at login). To view the required JSON format, click on a command below and look at the example request body. To try out an API, modify the request as needed, and press Send.

HTTP Endpoints

[POST]
/userData
 Register a userData If successful, an authorization authData is returned. You may use the authData with future requests that require authorization. No authorization authData is required to call this endpoint.
[POST]
/session
 Log in a userData If successful, an authorization authData is returned. You may use the authData with future requests that require authorization. No authorization authData is required to call this endpoint.
[DELETE]
/session
 Logs out an authenticated userData An authData is required to call this endpoint.
[GET]
/gameData
 Lists all the games in the database This API does not take a request body. The response JSON lists all the games, including the board. An authData is required to call this endpoint.
[POST]
/gameData
 Create a new Chess Game The request body must contain a name for the gameData. The response JSON contains the ID of created gameData, or if failed, an error message describing the reason. An authData is required to call this endpoint.
[PUT]
/gameData
 Join a Chess Game The request body must contain the gameData ID and player color. An authData is required to call this endpoint.
[DELETE]
/db
 Clear ALL data from the database This includes users and all gameData data. No authorization authData is required.
